# Security

Do not post suspected vulnerabilities, API keys, private transcripts, or exploitable details in public issues or pull requests. Follow [OpenAI's coordinated vulnerability disclosure policy](https://openai.com/policies/coordinated-vulnerability-disclosure-policy/) for the current private reporting routes and program scope. Include the affected repository revision and a minimal, sanitized reproduction. Eligibility for a bounty or testing authorization is determined by that policy, not this sample.

This application is a local educational sample, provided as-is. Its loopback, origin, cookie, CSRF, and tool controls are not production multi-user authentication. Do not expose it through a tunnel or public reverse proxy. Use a dedicated API project, monitor usage, keep dependencies current, and never disable TLS verification.

Security maintenance targets the current repository version; there is no separate long-term-support branch or guaranteed response time. For ordinary setup or usage bugs, follow [CONTRIBUTING.md](CONTRIBUTING.md).
